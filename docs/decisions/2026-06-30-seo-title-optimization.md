## 判断
GSC の28日間データで CTR が極端に低い記事のタイトルを改善する。
全39件中、インプレッションが高くCTRが低い上位3件を優先。

## 根拠

### 1. /archives/3017 — X(Twitter)「特定の人」エラー
- インプレッション: 42,330 / CTR: 0.57% / 順位: 8.83位
- 現状タイトル: `X(Twitter)で「ポストを読み込めません（特定の人）」エラーの原因と対処法`
- 問題点: 「原因と対処法」が曖昧。検索ユーザーは即効性のある解決策を求めている
- **改善案**: `X(Twitter)「特定の人のポストを読み込めません」エラーを今すぐ解決する7つの方法`
- 期待効果: CTR 0.57% → 2.0%+（約+250%）。クリック数: 241 → 846+

### 2. /archives/4154 — X(Twitter) 全般エラー一覧
- インプレッション: 4,926 / CTR: 0.20% / 順位: 9.53位
- 現状タイトル: `X(Twitter)の「ポストを読み込めません」「取得できません」エラー一覧と完全対処法`
- 問題点: タイトルが長く焦点がぼやけている。キーワードが散っている
- **改善案**: `X(Twitter)「ポストを読み込めません」「取得できません」完全ガイド｜原因別の即効対処法10選`
- 期待効果: CTR 0.20% → 1.5%+。クリック数: 10 → 73+

### 3. /archives/121 — ChatGPT エラー
- インプレッション: 1,646 / CTR: 0.30% / 順位: 7.99位
- 現状タイトル: `ChatGPT「Something went wrong while generating the response」エラーの原因と対処法`
- **改善案**: `ChatGPT「Something went wrong」エラーの直し方｜5つの原因と今すぐ試せる5つの対処`
- 期待効果: CTR 0.30% → 2.5%+。クリック数: 5 → 41+

## 実装
WordPress REST API 経由で全3件のタイトルを更新済み（2026-06-30）。
IndexNow 通知も送信済み。

2026-07-14（2週間後にCTR改善を確認）
