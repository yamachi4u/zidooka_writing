# ZIDOOKA Writing Style Guide

> 目的: AI臭さを消し、「このブログの人間が書いた」と思わせる。
> 参照: AGENTS.md#Conventions, docs/snippets/emphasis.md
>
> このガイドは「禁止リスト」じゃない。書いたあとにかける「リズム調整」の道具箱。

---

## 0. トーン: かるめのですます調

- 基調は **ですます調**（「〜です」「〜ます」「〜でした」）
- でも固くしない。**軽めに**。話し言葉に近い距離感。
- 語尾を「〜んです」「〜のです」にすると柔らかくなる
- 必要なら「〜だな」「〜だよね」を混ぜて崩す（やりすぎ注意）

例:
> この方法には注意点があるんです。というのも、効果には個人差が大きいんですね。

やってOK:
- 「〜んです / 〜のです」
- 「〜ですが / 〜けど」
- 「〜ですね / 〜ですよ」
- 「〜かなと思います」

やりすぎ注意:
- 「〜っす」「〜だぜ」「〜じゃん」
- 絵文字・顔文字

## 1. 大前提

AI臭いの正体は「構文とリズムの単調さ」であって単語の問題ではない。
だから「〜と言えるでしょうを避けよう」みたいな局所対応では直らない。
**書き終わった後に、以下のテクニックで文章のリズムを崩す** のが本質。

---

## テクニック1: 文末の三拍子

AIは文末が「〜だ/〜である/〜のだ」に偏る。書いたら意識的に散らす。

```
断定 — 「〜だ」「〜である」
意見 — 「〜と思う」「〜感じる」
観察 — 「〜ことがある」「〜ものだ」
```

悪い例:
> この方法は効率的である。コストも削減できる。導入も簡単である。

直した例:
> この方法は効率的だ。コストも削れて、導入も簡単に感じる。

1段落で同じ文末が2回来たら違う形に変える。それだけ。

---

## テクニック2: 「ため」「により」「において」を消す

AIが一番乱用するのがこの3つ。機械的に探して消すだけで劇的に変わる。

| 書いたやつ | 直す |
|-----------|------|
| 〜ため | 〜ので / 〜から / 消す |
| 〜により | 〜で / でね / 消す |
| 〜において | 〜では / 〜って / 消す |

悪い例:
> 本サービスにおいては、ユーザー登録を行うことにより、すべての機能を利用することができる。

直した例:
> このサービスはユーザー登録すれば全部使える。

**「ため」を探しては消す**。これだけで8割変わる。

---

## テクニック3: 長い修飾節をぶった切る

AIは「〜なAが〜するBを〜する」の入れ子構造が好き。人間は読めない。

悪い例:
> デジタルマーケティングの急速な発展に伴い従来の手法では対応困難になった課題を解決するソリューションが求められている。

直す:
> デジタルマーケティングが急速に発展している。従来の手法ではもう対応できない。この課題を解決するソリューションが今、求められている。

目安: **1文80字**。超えたら切る。

---

## テクニック4: 文頭パターンをローテーション

AIは段落の先頭を「また〜」「しかし〜」「例えば〜」で始める確率が異常に高い。

書いたら以下の4種で散らす:
1. 名詞/体言止め — 「理由は単純だ」「肝心なのは速度だ」
2. 指示語 — 「これが曲者だ」「その方法とは」
3. 問いかけ — 「なぜこんなことが起きるのか？」
4. ぶった斬り — 接続詞なしでいきなり内容から入る

---

## テクニック5: 体言止め＋疑問形で間を作る

AIの文章は情報密度が均一で「間」がない。以下の順でリズムを作る:

```
体言止めで一旦止める → 疑問形で問いかける → 答える
```

例:
> この技術がもたらすもの。それはコスト削減だ。どれくらい削れるのか？ ケースによるが、最大30%という試算もある。

---

## テクニック6: 書き終えた後の4フィルター

公開前に以下の観点で通す:

1. **「ため」フィルター**: 「〜ため」を全部検索。機械的に消せるか試す
2. **「おいて」フィルター**: 「〜において」「〜による」「〜に関する」を全部検索
3. **「様々」フィルター**: 「様々」「多くの」を全部検索。数字か具体に置き換えられる？
4. **80字フィルター**: 1文80字超えを全部分割

---

## テクニック7: 書いた直後に最初の段落を消してみる

AIが書いた文章の最初の段落は大体要らない。「定義→概要」のテンプレートが一番AI臭い。
最初の段落を消して、2段落目から始めてみる。それだけで見た目が変わる。

---

## テクニック8: 実体験を1文入れる

「私はこの方法でハマった」「試したらこうなった」
この1文が入るだけでAI臭がほぼ消える。AIは実体験を持たないので、これは人間にしか書けない。

---

## 英語記事への適用

同じ考え方。単語の禁止リストではなく：

- 短い文と長い文を交互に
- 接続詞で段落を始めない
- 書き終わったら最初の段落を消してみる
- 実体験を1文入れる
