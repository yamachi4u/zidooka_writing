# Glossary

| 用語 | 説明 |
|------|------|
| OKF | Open Knowledge Format — プレーンな Markdown + YAML frontmatter で知識を構造化する形式 |
| PostHog | プロダクトアナリティクス + A/Bテストプラットフォーム |
| GA4 | Google Analytics 4 |
| GSC | Google Search Console |
| IndexNow | Bing の URL 即時通知プロトコル |
| RPM | Revenue Per Mille（1000インプレッションあたりの収益） |
| ADR | Architecture Decision Record — 本KBでは「判断記録」と呼ぶ |
| forceInit | PostHog SDK の強制初期化（`posthog.forceInit()`） |
| server-side assignment | PHP の body_class フィルタで variant を割当 + cookie 固定する方式 |
| Netlify CLI 問題 | Windows で edge function bundling が壊れている問題 |
