## 9. PostHog A/B 実験提案

現在アクティブな実験はなし。以下の実験を提案する。

### 実験 A: カレンダーページCTA最適化

| 項目 | 内容 |
|-----|------|
| **仮説** | カレンダーページに「今日の吉日」ウィジェットを追加するとエンゲージメントが向上する |
| **フラグ** | `zdk_calendar_today_cta` |
| **ターゲット** | `/jp/calendar/*` 訪問者 |
| **バリアント** | Control: 現状 / Treatment: サイドバーに「今日の吉日」+ 関連記事リンク |
| **計測指標** | `calendar_date_detail_open`, `scroll`, `click` |
| **期间** | 14日間 (最低200imp/variant) |
| **優先度** | 中 |

**根拠**: カレンダーページはエンゲージメントが高く (85%+)、滞在時間も長い。追加CTAでさらなるエンゲージメント向上が期待できる。

### 実験 B: エラー記事の関連リンク最適化

| 項目 | 内容 |
|-----|------|
| **仮説** | エラー記事下部に関連エラー記事をレコメンドするとPV/ユーザーが増加する |
| **フラグ** | `zdk_related_errors` |
| **ターゲット** | カテゴリ"エラー"の記事訪問者 |
| **バリアント** | Control: 現状の関連記事 / Treatment: エラーカテゴリ特化のレコメンド表示 |
| **計測指標** | `user_engagement`, `scroll`, PV/セッション |
| **期間** | 14日間 |
| **優先度** | 高 |

**根拠**: エラー記事がトラフィックの大半を占めており、関連記事誘導で滞在時間・PV向上が見込める。

### 実験 C: モバイル用スティッキー目次

| 項目 | 内容 |
|-----|------|
| **仮説** | モバイルでスティッキー目次を表示するとエンゲージメントが向上する |
| **フラグ** | `zdk_mobile_toc` |
| **ターゲット** | モバイルデバイス、記事ページ訪問者 |
| **バリアント** | Control: 現状 / Treatment: スティッキー目次+スクロール追従 |
| **計測指標** | `scroll`, `user_engagement`, 直帰率 |
| **期間** | 10日間 |
| **優先度** | 低 |

### 推奨スケジュール

| 順番 | 実験 | 開始目安 | 期間 |
|-----|------|---------|------|
| 1 | B: 関連リンク最適化 | 今週中 | 14日間 |
| 2 | A: カレンダーCTA | B終了後 | 14日間 |
| 3 | C: モバイル目次 | A終了後 | 10日間 |
