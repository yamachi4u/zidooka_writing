# ChatGPT Draft Publication Rules

Scope: Applies to all files under `drafts/chatgpt/`.

## Privacy and Generalization

- Do not publish the user's personal or private context unless the user explicitly requests that specific information to appear in the article.
- Treat personal research topics, unpublished manuscripts, employment details, health information, travel/location details, relationships, finances, and other private life context as non-public by default.
- When private context is only needed to explain how a technical insight arose, generalize it. Examples:
  - `博士論文` / a dissertation -> `ある資料`, `ある文書`, or `a document`
  - a named private project -> `あるプロジェクト` or `a project`
  - a personal workflow -> `ある作業環境` or `a workflow`
- Prefer transferable technical lessons over autobiographical framing.
- Before publication, scan the draft for names, affiliations, unpublished research details, precise locations, and other identifying context that is not necessary for the article.
- These privacy rules override stylistic preferences when there is a conflict.
