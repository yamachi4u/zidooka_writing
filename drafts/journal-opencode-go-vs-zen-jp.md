OpenCode には2つの課金モデルがあります。Go（月額定額）と Zen（従量課金）。どちらを選ぶべきか、実際に両方使ってみた視点で比較します。

結論を先に言うと、**Codex CLI + Go + DeepSeek V4 Pro が現状最強のコスパ**だと個人的には思っています。

---

## Go と Zen の基本比較

| 項目 | Go | Zen |
|------|----|-----|
| 課金形態 | 月額定額 $10（初月$5） | 従量課金（$20チャージ〜） |
| 利用枠 | $12/5時間・$30/週・$60/月 | チャージ残高を消費 |
| 使えるモデル | オープンモデルのみ | オープン＋プロプライエタリ |
| DeepSeek V4 Pro | ○（Go専用） | × |
| Claude / GPT / Gemini | × | ○ |
| チーム機能 | × | ○（権限管理・BYOK） |
| オーバーフロー | Zen残高で継続可能 | チャージ追加 |
| 無料モデル | ○ 枠内で使える | ○ Big Pickle等 |

---

## モデルの違いが一番大きい

Go で使えるのはオープンモデルのみ。Zen は Claude Opus 4.7 や GPT-5.5 といった最高峰のプロプライエタリモデルにもアクセスできます。

**【Go限定】DeepSeek V4 Pro は実質 Go 専用**

Zen の価格表に DeepSeek V4 Pro は載っていません。V4 Pro を使いたいなら Go か、DeepSeek に直接API契約する必要があります。

Zen にある DeepSeek V4 Flash Free は無料ですが、V4 Pro ではありません。

---

## コスト計算（実践編）

OpenCode が公開している推定トークンパターンを使って、実際のコストを計算します。

### DeepSeek V4 Pro の場合

**Go（月$10固定）:**
- 3,450リクエスト/5時間
- 月17,150リクエストまで枠内
- 1リクエストあたり約$0.00058（17,150で割った場合）

**DeepSeek 直契約の場合:**
- 17,150リクエスト × $0.000875 = **$15.00/月**
- つまりGoのほうが安いし、OpenCode統合の利便性もある

### ライトユーザー（月1,000リクエスト程度）

| 構成 | 月額コスト |
|------|----------|
| Goだけで使う | $10 |
| DeepSeek直契約 | ~$0.88 |
| Zen（Qwen3.5 Plus等） | ~$0.50〜2 |

月1,000リクエストなら直契約が最安ですが、APIキー管理やモデル切り替えの手間を考えるとGoの$10も悪くない。

### ヘビーユーザー（月20,000リクエスト以上）

| 構成 | 月額コスト |
|------|----------|
| Goだけで使う | $10（枠超えはZen残高へ） |
| DeepSeek直契約 | ~$17.50〜 |

Go の月間枠は$60相当なので、DeepSeek V4 Pro を月17,150以上使うなら枠超え分は Zen 残高にフォールバック。それでも合計コストは直契約より安いか同程度。

### Claude Opus 4.7 と併用する場合

Go では Claude が使えないので、Claude も使いたいなら Zen が必要。

| 構成 | 月額コスト目安 |
|------|--------------|
| Go（DeepSeek用）+ Zen（Claude用） | $10 + 従量課金 |
| Zenだけで全部まかなう | 従量課金のみ |
| DeepSeek直契約 + Zen（Claude用） | 従量課金のみ×2 |

Claude を月に少しだけ使うなら Zen だけで十分。Claude をヘビーに使うなら、素直に Claude 直契約したほうが安い。

---

## 誰が何を選ぶべきか

### Go をおすすめする人

- **Codex CLI ユーザー**: Codex + Go + DeepSeek V4 Pro は現状最強のコスパ
- **DeepSeek V4 Pro をメインで使いたい**: Go 専用モデル。$10で使い放題に近い
- **月の使用量が読めないけどとにかく安く**: $10固定なら安心
- **オープンモデルで十分**: コーディングエージェント用途なら DeepSeek V4 Pro や Qwen3.5 Plus で事足りる

### Zen をおすすめする人

- **Claude / GPT-5 / Gemini が必要**: プロプライエタリモデルを使いたいなら必須
- **たまにしか使わない**: 月に数百リクエストなら従量課金のほうが安い
- **チームで運用する**: 権限管理や月間制限が設定可能
- **自分のAPIキーを持ち込みたい**: BYOK 対応

### 両方使うのがベストな人

Go に加入して普段は DeepSeek V4 Pro、枠を超えたら Zen 残高にフォールバック。さらに Claude が必要なときだけ Zen で都度払い。これが最も柔軟な構成です。Go は「フォールバックに Zen 残高を使う」設定が可能なので、枠を超えても自動で切り替わります。

---

## なぜ Codex + Go + DeepSeek V4 Pro が最強か

DeepSeek V4 Pro のデザインセンスは Claude Opus 系統に迫ります。フロントエンドのUI生成やビジュアル面の品質が、オープンモデルとしては異例に高い。にもかかわらず価格はClaudeの**数十分の一**。

それを Codex CLI を「司令塔」として使役することで、安くてデザインのいいコードをエージェントに生成させられます。Codex CLI のエージェント性能の高さ + Go の定額の安さ + DeepSeek V4 Pro の品質、という3拍子が揃っています。

:::conclusion
- オープンモデルだけでいいなら **Go（$10/月）**
- Claude/GPTが必要なら **Zen（従量課金）**
- 最強のコスパを求めるなら **Codex + Go + DeepSeek V4 Pro**
- 両方契約して「Go メイン＋Zen フォールバック」もアリ
:::
