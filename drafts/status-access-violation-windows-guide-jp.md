## はじめに

Windows でアプリケーション使用中に、以下のエラーが発生することがあります。

> STATUS_ACCESS_VIOLATION (0xC0000005)
> （例外コード: アクセス違反）

このエラーは、プログラムがアクセス権のないメモリ領域に読み書きしようとしたときに発生します。一見すると深刻に見えますが、適切な対処で解決できるケースがほとんどです。

:::conclusion
STATUS_ACCESS_VIOLATION の原因は「メモリ破損」「ドライバ不具合」「Visual C++ ランタイム破損」「アプリケーションのバグ」の4パターンが大半です。セーフモードで起動して切り分けを行います。
:::

## 原因別の対処法

### 1. 特定のアプリケーションのみで発生する

**原因**: アプリケーション自体のバグ、または Visual C++ ランタイムの破損

**対処**:
1. アプリケーションを最新バージョンにアップデート
2. Visual C++ 再頒布可能パッケージを再インストール
3. アプリケーションの設定をリセット（設定ファイルを削除）

### 2. ブラウザ（Chrome / Edge）で頻発する

**原因**: ブラウザの拡張機能・キャッシュ破損・GPUドライバの問題

**対処**:
1. 拡張機能をすべて無効にして再起動
2. ブラウザの設定 → 詳細設定 → ハードウェアアクセラレーションをオフ
3. GPU ドライバを最新にアップデート
4. ブラウザをリセット

### 3. システム全体で発生する

**原因**: メモリ（RAM）の物理故障、ドライバの不具合、システムファイルの破損

**対処**:
1. `sfc /scannow` でシステムファイルをチェック
2. `chkdsk /f` でディスクエラーをチェック
3. `mdsched.exe` でメモリ診断を実行
4. セーフモードで起動して問題が再現するか確認

### 4. 特定のゲームで発生する

**原因**: グラフィックドライバの問題、ゲームの設定過多、メモリ不足

**対処**:
1. グラフィック設定を下げる
2. GPU ドライバをクリーンインストール
3. DirectX / Visual C++ ランタイムを再インストール
4. ゲームファイルの整合性を確認（Steam 等）

## 予防策

- Windows Update を常に最新に保つ
- ドライバは安定版（ベータ版ではない）を使う
- メモリを増設する場合は同じメーカー・同じ仕様のモジュールを使う
- 定期的に `sfc /scannow` を実行する

## まとめ

STATUS_ACCESS_VIOLATION は「ソフトウェアのバグ」か「メモリ関連のハードウェア問題」のどちらかです。特定アプリ限定ならソフトウェア対処、システム全体ならハードウェア診断が基本です。メモリ診断ツール（mdsched.exe）を使えば物理的な故障かどうかを切り分けられます。
