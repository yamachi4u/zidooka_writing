Facebook広告を出稿しようとしたら、突然こんなエラーが出て止まったことはありませんか？

```
DofAssetFeedSpecFieldsCanNotContainDuplicateValue:
Dofがオンになっている広告から、bodies内の重複値を削除してください。
```

見慣れないエラー名で戸惑うかもしれませんが、原因はシンプルです。この記事ではエラーの意味と解決手順を解説します。

:::note
エラーコードの **Dof** は **Degrees of Freedom（自由度）** の略です。Meta広告の動的クリエイティブ機能で、見出し・本文・画像などの要素を自動で組み合わせて最適なパターンを配信する仕組みです。
:::

## エラーの原因

Dof（Degrees of Freedom = 自由度）が有効な広告では、見出し（titles）、本文（bodies）、説明文（descriptions）などのクリエイティブ要素を複数登録し、Meta側が自動で最適な組み合わせをテストします。

このとき、**同じ内容の本文（bodies）が重複して登録されている**と、Metaのバリデーションに引っかかり、上記のエラーが発生します。

例えば、以下のようなケースです：

- 本文の選択肢にまったく同じテキストが2つ以上含まれている
- スペースや句読点の違いだけで実質的に同じ内容
- API経由でアセットフィードを登録する際に重複した値を送信してしまった

:::warning
スペースや改行の有無といった軽微な違いは許容されますが、表示上まったく同じ文字列が複数あるとエラーになります。また、このエラーは **bodies（本文）** だけでなく **titles（見出し）** や **descriptions（説明文）** でも発生することがあります。
:::

## 対処方法

### 1. 広告クリエイティブの本文を確認する

Facebook広告マネージャーで該当の広告を開き、クリエイティブ部分の「本文」を確認します。

### 2. 重複を削除または修正する

同じ本文が複数設定されている場合は、重複を削除するか、それぞれ異なる文章に変更します。

:::step
1. 広告マネージャーで該当の広告を編集モードで開く
2. 「クリエイティブ」→「本文」の一覧を確認する
3. まったく同じ本文があれば、1つだけ残して削除する
4. または、重複している本文を別のバリエーションに書き換える
5. 変更を保存して再度公開を試す
:::

### 3. APIで運用している場合

広告運用をAPI経由で行っている場合は、`AssetFeedSpec` の `bodies` 配列に重複した値が含まれていないかチェックしてください。

```javascript
// 重複チェックの例
const bodies = ["テキストA", "テキストB", "テキストA"]; // テキストAが重複！
const unique = [...new Set(bodies)];
// unique = ["テキストA", "テキストB"] → 重複除去
```

:::conclusion
**DofAssetFeedSpecFieldsCanNotContainDuplicateValue** エラーは、動的クリエイティブ広告の本文（bodies）に重複があるという単純なバリデーションエラーです。広告マネージャーで重複した本文を削除するだけで解決します。API運用の場合はアセットフィードの値をユニークにしてから送信しましょう。
:::
