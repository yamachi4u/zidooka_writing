Qiita や Zenn、GitHub のREADMEなど、Markdownで書かれたテーブルを画像として保存したいことはありませんか？ブログ記事に貼りたい、SNSで共有したい、といったケースで重宝します。

---

## Markdown Table to Image の使い方

[Markdown Table to Image](https://tools.zidooka.com/markdown-table-to-image) は、Markdownの表を画像に変換するツールです。

1. [Markdown Table to Image](https://tools.zidooka.com/markdown-table-to-image) を開く
2. 左側のエディタにMarkdownテーブルを貼り付ける
3. 右側にリアルタイムでプレビューが表示される
4. フォント・サイズ・スケール・色を好みに調整
5. PNG または JPG でダウンロード

### 便利ポイント

- セル内の **太字** や *斜体* も反映される
- カラープリセットで見た目を簡単変更
- 画像の横幅も自由に指定可能
