If you use GitHub for personal projects, work, and automation, it is natural to wonder whether you can simply create several free accounts for different purposes.

The short answer is: ==under GitHub's Terms of Service, one person or legal entity may generally maintain no more than one free account==.

## One regular free personal account

GitHub's Terms of Service state in the account requirements that one person or legal entity may maintain no more than one free account.

So creating two or three ordinary GitHub Free personal accounts simply to separate different kinds of work is not the intended arrangement under the Terms.

GitHub Free already allows unlimited public repositories and unlimited private repositories, so separating projects usually does not require separate personal accounts.

## Exception: one free machine account

There is an explicit exception. In addition to a free Personal Account, GitHub allows you to maintain ==one free machine account used for running a machine==.

This should not be treated as an ordinary second personal identity. It is intended for automated activity, such as a bot or service account that needs its own GitHub identity.

For a fuller explanation, see the separate article "What Is a GitHub Machine Account?".

:::warning
A machine account is not a general-purpose alternative personal account. Using it as a second everyday identity would not match the purpose described in GitHub's Terms.
:::

## What about separating work and personal use?

GitHub recommends using one Personal Account for your work on GitHub.com unless you specifically need another account type, such as an account managed by an employer through Enterprise Managed Users.

For normal separation of projects and permissions, Organizations are usually the better model. A single Personal Account can belong to multiple Organizations.

In enterprise environments, you may legitimately use both your Personal Account and a company-managed user account. GitHub also provides an account switcher for situations where multiple account types are required.

## Summary

:::conclusion
For ordinary GitHub Free personal accounts, the rule is essentially one free account per person or legal entity. GitHub also permits one additional free machine account for automation. If you simply need to separate projects, repositories and Organizations are usually the appropriate solution rather than creating extra free personal accounts.
:::
