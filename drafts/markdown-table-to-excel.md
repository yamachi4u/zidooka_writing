Markdownで書かれたテーブルをExcelやGoogleスプレッドシート、PowerPointのスライドに貼り付けたい場面はよくあります。でも、単純にコピペすると書式が崩れたり、セルが1つにまとまってしまったりします。

---

## Markdown Table → コピー用テーブルの使い方

[Markdown Table → Copy](https://tools.zidooka.com/markdown-to-table) は、Markdownの表をExcelやスライドに貼り付けられる形式に変換します。

1. [Markdown Table → Copy](https://tools.zidooka.com/markdown-to-table) を開く
2. Markdownテーブルを入力
3. カラープリセットとフォントを選択
4. 「Excel / スライドに貼付」をコピー
5. Excel・スプレッドシート・PowerPointで貼り付け

### コピー形式の選び方

| ボタン | 用途 |
|--------|------|
| Excel / スライドに貼付 | 書式付きテーブルとしてコピー（推奨） |
| TSV（値のみ） | 値だけExcelに貼り付け |
| HTML | 装飾付きHTMLコード |
| CSV | カンマ区切りテキスト |

---

:::conclusion
Markdownの表をExcelやスライドに貼り付けるなら **Markdown Table → Copy** を使いましょう。色付きの装飾テーブルをそのまま貼り付けられます。
:::
