GitHubの無料プランだと、「リポジトリは10個まで」「プライベートリポジトリには上限がある」と思っていました。

しかし、現在のGitHub Freeでは、==個人アカウントが所有できるパブリックリポジトリとプライベートリポジトリの数はどちらも無制限です==。

## GitHub Freeでもリポジトリ数は無制限

GitHub公式ドキュメントでは、GitHub FreeのPersonal Accountについて、パブリック・プライベートともに無制限のリポジトリを所有できると明記されています。

つまり、無料だから「プロジェクトが増えたら古いリポジトリを消す」といったことは基本的に必要ありません。

## ただし、何もかも無制限ではない

リポジトリの**個数**は無制限ですが、GitHub Freeには別の制限があります。たとえばプライベートリポジトリでは一部の高度な機能が有料プラン向けで、GitHub Actionsにも無料利用枠があります。

なので、「GitHub Freeには制限がない」というより、==リポジトリを作れる個数には制限がない==と理解するのが正確です。

:::conclusion
GitHub Freeでは、個人アカウントのパブリックリポジトリもプライベートリポジトリも作成数は無制限。個人開発や小さなプロジェクトごとにリポジトリを分けても、リポジトリ数を気にする必要はほぼありません。
:::
