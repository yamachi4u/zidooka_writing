Trello を開いたとき、画面上部に次のような茶色のバナーが出ることがあります。

![Trello の障害告知バナー](C:/Users/user/Pictures/screenshots/スクリーンショット 2026-05-19 093652.png)

> 現在、いくつかの問題が発生しています。早急な解決に向け対応しておりますのでしばらくお待ちください。

:::conclusion
この表示は、Trello 側で一部機能の障害や性能低下が起きているときに出る告知です。自分のPCやブラウザだけの問題と決めつけず、まず公式ステータスを確認するのが早いです。
:::

## 何が起きている？

2026年5月19日朝の時点で、Trello の公式ステータスページには `Trello - degraded performance` というインシデントが掲載されています。

公式ページでは、コメント、カードのアクティビティ、添付ファイル、Power-Up、ボードエクスポート、ホーム画面の更新表示、検索、一部カードの表示などに影響が出る可能性が説明されています。

また、2026年5月18日 18:45 EDT の更新では、大規模データベースの最適化後に一部パーティションでインデックスがない状態になり、該当パーティションへの問い合わせがタイムアウトしている、という趣旨の説明が出ています。日本時間では 2026年5月19日 7:45 頃の更新です。

参考：

- [Trello Status](https://trello.status.atlassian.com/)

:::note
ステータスページは随時更新されます。この記事を読んでいる時点では、すでに復旧済み、または影響範囲が変わっている可能性があります。
:::

## まず確認すること

このバナーが出たら、最初に公式ステータスを確認します。

1. [Trello Status](https://trello.status.atlassian.com/) を開く
2. `Trello.com` や `API` が `Degraded Performance` になっていないか見る
3. インシデントの最新更新時刻を確認する
4. 自分の症状が、コメント、添付、検索、カード表示などの影響範囲に含まれているか見る

公式ステータスで障害が出ているなら、ブラウザ設定を大きく変えるより、復旧を待つ方が現実的です。

## こちらでできる対処

作業を続ける場合は、次の順で確認します。

1. ページを再読み込みする
2. 数分から数十分待って再度開く
3. 重要なカードの編集内容は、念のため別メモにも控える
4. コメントや添付ファイルの追加は、復旧後に反映を確認する
5. 急ぎの共有は Slack、メール、Google Docs など別経路に逃がす

:::warning
公式ステータスで障害が出ている間は、カードやリストの移動・コピーなど、影響範囲に入りそうな操作は急がない方が安全です。Trello 側の復旧が進んでから、反映状況を確認しましょう。
:::

## 自分だけの問題かどうかを切り分ける

公式ステータスが正常なのに自分だけエラーが続く場合は、ローカル環境の問題も確認します。

1. 別ブラウザで Trello を開く
2. シークレットウィンドウで開く
3. VPN やプロキシを一時的に切る
4. 会社や学校のネットワーク制限がないか確認する
5. Trello からログアウトして再ログインする

ただし、同じタイミングで公式ステータスにインシデントが出ているなら、まずはサービス側の問題として扱うのが自然です。

## まとめ

Trello の「現在、いくつかの問題が発生しています」というバナーは、Trello 側の障害や性能低下を知らせる表示です。

まず [Trello Status](https://trello.status.atlassian.com/) を確認し、影響範囲と更新時刻を見ましょう。障害中は、カードやコメントが一時的に見えない、反映が遅い、検索が追いつかないといった症状が出ることがあります。急ぎの作業は別ツールに一時退避し、復旧後に Trello 側の反映を確認するのが無難です。
