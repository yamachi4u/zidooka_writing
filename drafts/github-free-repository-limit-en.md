You might expect GitHub's free plan to limit the number of repositories you can create, especially private repositories.

It does not. ==A GitHub Free personal account can own an unlimited number of both public and private repositories.==

## Unlimited repositories on GitHub Free

GitHub's official documentation states that personal accounts can own unlimited public and private repositories.

So you generally do not need to delete old repositories just because you keep creating new projects.

## Not everything is unlimited

The **number of repositories** is unlimited, but GitHub Free still has limits elsewhere. Some advanced features for private repositories require a paid plan, and GitHub Actions has usage allowances for private repositories.

So the precise takeaway is not that GitHub Free has no limits. It is that ==there is no repository-count limit for personal accounts==.

:::conclusion
GitHub Free personal accounts can own unlimited public and private repositories. For personal development and small projects, you can split work into separate repositories without worrying about a repository-count quota.
:::
