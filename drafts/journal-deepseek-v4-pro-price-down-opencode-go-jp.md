DeepSeek V4 Pro の API 価格が実質75%引きになりました。それを受けて、OpenCode Go の DeepSeek V4 Pro 利用枠に変更があるのか調べてみました。

結論から言うと、**現時点で利用枠は値下げ前の価格で計算されたまま**で、変更は反映されていません。

:::note
この記事は 2026年5月26日時点の情報に基づきます。DeepSeek の75%割引キャンペーンは 2026/5/31 15:59 UTC までで、その後は恒久的に1/4の価格に正式改定されます。
:::

## DeepSeek V4 Pro の価格改定

DeepSeek V4 Pro は 2026年4月24日にリリースされました。その後の価格改定で、現在は**オリジナル価格の1/4**で利用できます。

| 項目 | オリジナル価格 | 現在価格（75%OFF） |
|------|---------------|-------------------|
| 入力（キャッシュミス） | $1.74 / 100万トークン | $0.435 / 100万トークン |
| 入力（キャッシュヒット） | $0.0145 / 100万トークン | $0.003625 / 100万トークン |
| 出力 | $3.48 / 100万トークン | $0.87 / 100万トークン |

キャッシュヒット価格はさらに以前（4/26）から1/10に引き下げられています。

## OpenCode Go の DeepSeek V4 Pro 利用枠

OpenCode Go（月額$10）の DeepSeek V4 Pro 利用枠は以下の通りです。

| 期間 | リクエスト数 | ドル建て枠 |
|------|------------|-----------|
| 5時間 | 3,450 | $12 |
| 週 | 8,550 | $30 |
| 月 | 17,150 | $60 |

## 値下げのインパクトを計算する

OpenCode が公開している推定トークンパターン（入力750・キャッシュ82,000・出力290）を使って、1リクエストあたりのコストを計算してみます。

**値下げ前のコスト:**
750×$1.74/1M + 82,000×$0.0145/1M + 290×$3.48/1M = **$0.003503/リクエスト**

3,450リクエスト × $0.003503 = **$12.09** → これは5時間枠の$12とほぼ一致します。

**値下げ後のコスト:**
750×$0.435/1M + 82,000×$0.003625/1M + 290×$0.87/1M = **$0.000875/リクエスト**

3,450リクエスト × $0.000875 = **$3.02**

:::conclusion
値下げ前は3,450リクエストで$12かかっていたのが、値下げ後は同じリクエスト数で約$3になりました。OpenCode 側のコストは**75%減少**しています。
:::

## もし利用枠が値下げを反映したら？

同じ$12の枠で新しい価格で計算し直すと：

$12 ÷ $0.000875 = **約13,700リクエスト/5時間**

現在の3,450の約4倍です。

| 項目 | 現在 | 理論上の上限 |
|------|------|------------|
| 5時間 | 3,450 | ~13,700 |
| 週 | 8,550 | ~34,200 |
| 月 | 17,150 | ~68,500 |

## なぜまだ反映されていないのか？

いくつかの可能性が考えられます。

1. **ドキュメント更新のタイミング**: Go のドキュメントは 5月25日更新で、価格改定後の状態かもしれませんが、利用枠は以前のままです。
2. **価格改定の正式適用が6月から**: DeepSeek の75%割引は5/31まで「キャンペーン」扱いで、6/1から正式に価格改定されます。OpenCode は正式改定を待って調整する可能性があります。
3. **調整中の可能性**: 裏側で変更の準備をしているかもしれません。

いずれにせよ、現時点ではGoユーザーは値下げ前の利用枠で運用されています。

## Go ユーザーにとっての実質的な価値

DeepSeek V4 Pro は Go 加入者の間でも人気のモデルです。仮に利用枠が引き上げられれば、実質的な価値が大きく向上します。

一方で、月額$10固定のため、今の枠でも不満を感じていないユーザーが大半でしょう。私の体感では、3,450リクエスト/5時間を超える使い方をする人は多くありません。

:::note
値下げの恩恵が利用枠の拡大という形でユーザーに還元されるかどうかは、OpenCode 側の判断次第です。引き続き動向を追ってみます。
:::
