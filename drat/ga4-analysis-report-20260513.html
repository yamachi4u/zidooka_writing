4. CTAクリックが実質ゼロ

cta_click = 2回、form_start = 2回、form_submit = 2回（30日間で）

6,970セッションに対してコンバージョン数が2。これはかなり低い。

原因推測: - CTAが記事下の方にあって見つけにくい - 「この記事の内容について相談する」の文言が行動を促せていない - エラーページで「解決策を探しに来た」ユーザーには案件相談系CTAがミスマッチ

やること: - エラー解決記事には「同じエラーでお困りですか？」のようなCTAに変える - 記事中の最初の解決策の直後に小さなCTAを追加 - CTAクリック自体をGA4イベントでもっと詳細に取れるようにする（今は2件しか取れてない）

5. ChatGPT / Copilot からの参照流入が大量

zdk_debug_search_boot = 3,609回（30日間）

これはChatGPTやCopilotの回答内でzidookaの記事がリンクされ、そこから訪れるユーザー。もう一つの重要なチャネル。

やること: - ChatGPT/Copilotの参照セッションのエンゲージメント率を計測する（今のGA4設定では取れてない） - もしエンゲージメントが高いなら、AI回答向けの記事構造（箇条書き・コードブロック・短い段落）を強化する

6. カレンダーページはエンゲージメント高いがSEO流入少ない

/jp/calendar/2026/05 は 422 sessions、engaged 324、平均391秒と高エンゲージメント。 しかし GSC トップには入ってこない（検索クエリが限定されるため）。

やること: カレンダーページからの内部リンクを強化して、記事への導線を増やす。

7. scroll イベントが1,082回（全セッションの15.5%）

スクロール計測は「最初の50%以上スクロール」で発火するデフォルト設定。15%はやや低い。

やること: GA4拡張計測機能でスクロール深度が正しく取れているか確認。もしまだなら「すべてON」にする（本人がやったと言っていたのでOKのはず）。
